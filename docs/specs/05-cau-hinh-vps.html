Chọn Meilisearch (mã nguồn mở, tự cài miễn phí trên VPS):

  • 10.000 mã hàng là quy mô nhỏ với Meilisearch: index vài chục MB, tìm < 50ms.
  • Có sẵn tìm không dấu, sửa lỗi chính tả, đếm bộ lọc, sắp xếp → làm được bộ lọc theo thương hiệu, giá, tính năng mà không phải tự viết.
  • PostgreSQL vẫn là dữ liệu gốc. Meilisearch chỉ là bản sao để tìm; hỏng thì dựng lại index trong ~1 phút.
  • Dự phòng: nếu Meilisearch tạm ngừng, API tự chuyển sang tìm bằng PostgreSQL (pg_trgm) → web không chết.
  • Elasticsearch quá nặng cho VPS 4GB; Typesense ngang Meilisearch nhưng cộng đồng nhỏ hơn.

3. docker-compose.yml

services:
  caddy:
    image: caddy:2-alpine
    restart: unless-stopped
    ports: ["80:80", "443:443"]
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - ./data/uploads:/srv/uploads:ro
      - caddy_data:/data
    mem_limit: 128m

  app:
    image: techhomes/web:latest            # build từ repo (Nuxt 3, Node 22)
    restart: unless-stopped
    env_file: .env
    environment:
      NODE_OPTIONS: --max-old-space-size=512
    volumes: ["./data/uploads:/app/uploads"]
    depends_on: [db, search]
    mem_limit: 768m

  db:
    image: postgres:16-alpine
    restart: unless-stopped
    environment:
      POSTGRES_DB: techhomes
      POSTGRES_USER: techhomes
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    command: >
      postgres -c shared_buffers=768MB -c effective_cache_size=2GB
               -c work_mem=8MB -c maintenance_work_mem=128MB
               -c max_connections=40 -c random_page_cost=1.1
    volumes: ["./data/pg:/var/lib/postgresql/data"]
    mem_limit: 1536m

  search:
    image: getmeili/meilisearch:v1.11   # ghim bản cụ thể; nâng cấp có kiểm thử
    restart: unless-stopped
    environment:
      MEILI_ENV: production
      MEILI_MASTER_KEY: ${MEILI_MASTER_KEY}   # >= 32 ký tự ngẫu nhiên
      MEILI_NO_ANALYTICS: "true"
      MEILI_MAX_INDEXING_MEMORY: 512Mb
      MEILI_MAX_INDEXING_THREADS: 1         # index không tranh CPU với web
    volumes: ["./data/meili:/meili_data"]
    mem_limit: 1g

6. Cấu hình index Meilisearch (products)

Áp tự động mỗi lần deploy (script npm run search:setup):

{
  "searchableAttributes": ["name", "sku", "sku_plain", "brand", "category", "tags", "short_desc"],
  "filterableAttributes": ["category", "type", "brand", "features", "size", "price", "discount", "in_stock", "visible"],
  "sortableAttributes": ["price", "created_at", "sold_count"],
  "rankingRules": ["words", "typo", "proximity", "attribute", "sort", "exactness", "sold_count:desc"],
  "typoTolerance": { "minWordSizeForTypos": { "oneTypo": 4, "twoTypos": 8 } },
  "synonyms": {
    "máy rửa chén": ["máy rửa bát"], "máy rửa bát": ["máy rửa chén"],
    "khóa điện tử": ["khóa thông minh"], "hút mùi": ["hút khói"],
    "chậu rửa": ["bồn rửa"]
  },
  "faceting": { "maxValuesPerFacet": 100 },
  "pagination": { "maxTotalHits": 5000 }
}
  • Đồng bộ: lưu/sửa/ẩn sản phẩm trong admin → đẩy ngay sang Meilisearch; mỗi đêm 02:00 dựng lại toàn bộ index từ PostgreSQL để chắc chắn khớp.
  • Bảo mật: website gọi Meilisearch qua API của Nuxt (không lộ key ra trình duyệt); Meilisearch không mở cổng ra Internet.
  • Mã hàng lưu thêm bản bỏ dấu chấm (sku_plain: 533.09.989 → 53309989) để gõ mã kiểu nào cũng ra.
  • Mỗi tài liệu chỉ chứa trường cần tìm/lọc (không chứa mô tả dài, giá vốn).

7. PostgreSQL

CREATE EXTENSION IF NOT EXISTS unaccent;
CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE OR REPLACE FUNCTION unaccent_immutable(text) RETURNS text
  LANGUAGE sql IMMUTABLE PARALLEL SAFE AS $$ SELECT public.unaccent('public.unaccent', $1) $$;
-- tìm dự phòng khi Meilisearch ngừng + ô tìm trong admin
CREATE INDEX products_name_trgm ON products USING gin (unaccent_immutable(name) gin_trgm_ops);

8. Bảo mật server

  • SSH chỉ đăng nhập bằng key, tắt đăng nhập root và mật khẩu; đổi cổng SSH nếu muốn.
  • ufw: chỉ mở 22, 80, 443. fail2ban cho SSH.
  • unattended-upgrades tự cập nhật bản vá bảo mật.
  • Cloudflare: bật proxy, "Always use HTTPS", chặn bot cơ bản; chỉ cho IP Cloudflare vào cổng 80/443.
  • Admin /admin: mật khẩu mạnh + 2FA; khoá tài khoản sau 5 lần sai.
