04 — Design system

1. Màu lấy từ logo

Logo ponagar-mark.png (160×158): ô vuông đỏ #BB2E30, nét chữ trắng. Đo trực tiếp trên file logo.

Token Giá trị Dùng cho
--brand #BB2E30 (đỏ logo) Header, nút chính, giá, nhãn, menu admin
--brand-dark / --brand-deeper / --brand-tint tự suy từ --brand (color-mix) Hover, nền banner, nền nhạt
--accent #F3E6CF (kem da thuộc) Nút phụ, khối đặt làm riêng, nhãn nổi
--ink #231F1C (nâu đen) Chữ chính
--muted #76695E Chữ phụ
--bg #FAF7F2 (nền giấy ấm) Nền trang
--border / --gray-bg #ECE4D8 / #F2ECE3 Viền, nền chip
--font-display Playfair Display (có tiếng Việt) Tiêu đề, tên thương hiệu

Nền kem + chữ nâu đen + đỏ logo gợi chất da thuộc thủ công, khác hẳn tông xanh/vàng của DMCL. Màu da sản phẩm (bò sáp, nâu bò, đỏ đô, xanh rêu…) là dữ liệu sản phẩm do admin nhập, không phải màu giao diện.

2. Cách áp dụng kit dmcl-shared

  1. tokens.css của @dmcl/design-tokens là nền. Không sửa kit.
  2. File ponagar-theme.css nạp ngay sau, chỉ override các anchor token ở trên → cả kit (nút, badge, bảng, sidebar admin) tự đổi sang đỏ Ponagar. Đây là cơ chế "núm chỉnh tone" mà kit thiết kế sẵn.
  3. Cấm hardcode mã màu trong view; mọi màu dùng var(--…). Màu Ponagar chỉ nằm trong ponagar-theme.css.
  4. Không Tailwind/Bootstrap; icon Tabler (ti ti-*) như kit.

3. Hai phần giao diện

Phần Dùng từ kit
Admin (/admin) Nguyên trạng: AppShell, BasePanel, Toolbar, BaseButton, BaseBadge, BaseModal persistent, FormSection, FormField, BaseCombobox, FilterableCheckboxList, StatCard, Skeleton, ErrorState, EmptyState, table.data
Website Tokens + class base (.btn, .badge, .chip, .field, .modal, .toast, .skeleton) + component riêng Shop* / class .shop-*

Không dùng StatusBadge/STATUS_META cho trạng thái đơn bán lẻ (trùng khoá với dmcl.delivery). Tạo SHOP_ORDER_META riêng trong app.

4. Component riêng của website

Component Dùng ở
ShopHeader (logo, tìm kiếm, ngôn ngữ, giỏ) · ShopMegaMenu Mọi trang
ShopProductCard (ảnh, chủ đề, tên, chấm màu da, giá) Trang chủ, danh mục, liên quan
ShopFacetPanel (bộ lọc + số đếm từ Meilisearch) Danh mục, tìm kiếm
ShopSwatches (chọn màu da) · ShopPaintName (vẽ tên miễn phí) Chi tiết SP
ShopCountdown · ShopContactBar (Gọi/Zalo/Messenger) Trang chủ, mọi trang
ShopCustomOrder (đặt làm riêng 3 bước) Trang chủ, trang đặt làm

5. Prototype

docs/prototype/: mở index.html. Thứ tự nạp CSS: tokens.css (bản sao từ dmcl-shared) → ponagar-theme.css → shop.css (website) hoặc admin.css (quản trị). Logo dùng trực tiếp từ CDN của ponagar.co.
