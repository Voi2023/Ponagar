02 — Đề xuất các việc cần làm

Ngân sách nhỏ nên nguyên tắc là: một ứng dụng, một server, tận dụng tối đa thứ đã có (kit UI dmcl-shared, dữ liệu trên Haravan, Cloudflare miễn phí).

1. Kiến trúc gọn

Khách ─► Cloudflare (DNS + CDN + SSL, miễn phí) ─► VPS 2 vCPU / 4GB
                                                    ├─ Caddy (reverse proxy)
                                                    ├─ Nuxt 3: website (SSR) + /admin (Vue + @dmcl/ui-kit) + API
                                                    ├─ PostgreSQL 16 (dữ liệu gốc)
                                                    ├─ Meilisearch (tìm kiếm + bộ lọc)
                                                    └─ Thư mục ảnh WebP (Cloudflare cache)
Đơn mới ─► hàng đợi ─► API phần mềm quản lý đơn (KiotViet / Sapo / Haravan / Nhanh.vn / Pancake)
       └─► báo Zalo / Telegram / email cho shop
  • Một codebase Nuxt 3 chứa cả website, trang quản trị và API → ít công nhất, dễ bảo trì.
  • Website render phía server (SSR) để Google đọc được (quan trọng khi rời Haravan).
  • Admin dùng nguyên AppShell, BaseModal, FormSection… của @dmcl/ui-kit → không thiết kế lại admin.
  • Chi tiết cấu hình server + search engine: 05 · Cấu hình VPS.

2. Dữ liệu 10.000 sản phẩm

Vấn đề Đề xuất
Lấy dữ liệu từ ponagar.co Xuất Excel sản phẩm từ Haravan → công cụ nhập tự đọc, tải ảnh về, nén WebP.
Màu da, chủ đề tranh nhập không đồng nhất Danh sách chuẩn (8 màu da, các chủ đề) + gợi ý sửa khi import.
Biến thể SP cha → biến thể (màu da × size); giá/tồn theo biến thể.
Ảnh nặng Mỗi ảnh tạo 3 cỡ (400/800/1600px), Cloudflare cache → VPS nhẹ.
Giữ SEO cũ Map URL Haravan cũ (/products/..., /collections/...) → 301 sang URL mới.

3. Đơn hàng → phần mềm quản lý đơn

Công ty chưa xác định phần mềm. Website làm sẵn bộ chuyển đổi (adapter), bản đầu kết nối 1 phần mềm công ty đang dùng:

Phần mềm Phù hợp với Kết nối
KiotViet Cửa hàng bán lẻ, quản lý kho + bán tại quầy, rất phổ biến Public API (tạo đơn đặt hàng)
Sapo (Sapo OMNI) Bán đa kênh: web, Shopee/TikTok, Facebook, cửa hàng API
Haravan (OmniPower) ponagar.co đang dùng Haravan → nếu giữ Haravan làm nơi quản lý đơn/kho thì ít thay đổi thói quen nhất API
Nhanh.vn Mạnh về kho + kết nối nhiều hãng vận chuyển API order/add
Pancake POS Bán chủ yếu qua Facebook/Instagram/livestream, chốt đơn inbox API
Chưa có / không có API — Báo đơn qua Zalo/Telegram + xuất Excel theo ngày

Gợi ý: nếu chưa dùng phần mềm nào → KiotViet (bán tại showroom + kho) hoặc Sapo (bán nhiều kênh online). Nếu đang quen Haravan → giữ Haravan làm nơi quản lý đơn. Lưu ý: cần kiểm tra gói đang thuê có mở API không (một số gói thấp không có).

Cách đẩy đơn: đơn lưu trên web trước → đẩy sang phần mềm qua hàng đợi → lỗi thì tự thử lại 5 lần, rồi báo đỏ trong admin để bấm "Gửi lại". Không bao giờ mất đơn khi phần mềm bên kia lỗi. Mỗi sản phẩm trên web lưu mã SP bên phần mềm quản lý để đơn đẩy sang khớp đúng hàng.

4. Tính năng học từ thienkimhome (làm theo kiểu Ponagar)

  • Menu lớn nhiều tầng, trang danh mục × chủ đề làm trang SEO (vd: túi da vẽ tay đồng quê).
  • Bộ lọc có số đếm, sắp xếp, phân trang; khối ưu đãi có đồng hồ đếm ngược.
  • Thanh Gọi / Zalo / Messenger dính màn hình, nút "Gọi lại cho tôi".
  • Khác biệt của Ponagar: câu chuyện bức tranh, vẽ tên miễn phí, đặt làm riêng, video xưởng.

5. SEO

  • Schema Product, Offer, BreadcrumbList, FAQPage, LocalBusiness (showroom).
  • Sitemap tự sinh (chia file ≤ 5.000 URL), canonical cho trang lọc, 301 từ URL Haravan cũ.
  • GA4 + Meta Pixel + Google Search Console.
