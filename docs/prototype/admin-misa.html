Giá bán đã gồm thuế. Chưa thuế = khách trả ÷ (1 + thuế suất), làm tròn đồng; thuế = khách trả − chưa thuế. Giảm giá chia theo tỉ lệ giá từng dòng rồi mới tách thuế. Đơn cũ giữ thuế suất cũ.

Cần kiểm lại với MISA

  • Gói AMIS Kế toán của Techhomes có mở API kết nối không, API có phí riêng không chờ Techhomes xác nhận
  • Truyền tiền thuế từng dòng theo số hệ thống gửi, hay để MISA tự tính lại chờ Techhomes xác nhận
  • MISA có trả số hoá đơn về qua API không (nếu có, bỏ bước dán tay) chờ Techhomes xác nhận
  • Phí giao hàng là doanh thu công ty hay thu hộ hãng vận chuyển chờ Techhomes xác nhận
