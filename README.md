# Techhomes — tài liệu dự án

Bộ tài liệu làm lại website bán hàng và hệ thống vận hành cho **Techhomes** (techhomes.vn — đại lý Hafele, Blum tại TP.HCM).

- `docs/specs/` — yêu cầu, đề xuất, báo giá, design system, cấu hình VPS (mở `docs/specs/index.html`)
- `docs/prototype/` — giao diện click được · `docs/tai-lieu/` — tài liệu chức năng

Các trang trong `docs/` có khoá mật khẩu (`docs/gate.js`); xin mật khẩu từ người quản lý dự án.
